# BrandProof AI — Frontend

A polished, enterprise-grade content quality assurance and brand governance platform frontend.
Built with React 19, TypeScript, Vite 8, Tailwind CSS v4, and Radix UI primitives.

## Quick Start

```bash
npm install
npm run dev
```

Open **http://localhost:5173** in your browser.

## Available Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Type-check and produce production build |
| `npm run lint` | Run oxlint across all source files |
| `npm run preview` | Preview the production build locally |

## Demo Mode

All data is generated by a deterministic demo engine in `src/services/demo.ts`.

- **Demo mode is always clearly labelled** — the `Demo Mode` badge appears in the sidebar and `Demo Alert` banners appear on relevant pages.
- The demo engine detects 15 representative language patterns (grammar, spelling, style, clarity, brand voice).
- Results are **deterministic** — the same input produces the same findings.
- No external network requests are made.
- All data persists in `localStorage` using versioned keys.

### Triggering demo findings

Use the **"Load sample text for demo"** link on the Analyse page, or manually include:
`alot`, `recieve`, `seperate`, `occured`, `in order to`, `utilize`, `leverage`, `e-mail`, `their is`, `due to the fact that`

## Local Persistence

Data is stored in browser `localStorage` under versioned keys:

| Key | Contents |
|-----|---------|
| `brandproof_analyses_v1` | Analysis history (full Analysis objects) |
| `brandproof_feedback_v1` | Finding feedback records |
| `brandproof_brand_profile_v1` | Brand knowledge profile |

Use **History → Clear Demo Data** to reset all stored data.
